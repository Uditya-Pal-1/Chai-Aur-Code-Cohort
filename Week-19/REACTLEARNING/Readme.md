# ⚛️ React Learning & Concepts Sandbox

Welcome to the **REACTLEARNING** module of Week 19! This folder is dedicated to exploring React fundamentals, state management, component re-renders, and modern build tooling using Vite.

---

## 📁 Directory Structure

```
REACTLEARNING/
└── 📁 React Practice/       # Interactive React playground application
    ├── src/                 # React components, custom hooks, and state logic
    ├── index.html           # Single Page Application entry HTML
    ├── vite.config.js       # Vite build configuration
    └── package.json         # Project metadata and dependencies
```

---

## 💡 Key Learning Objectives

1. **React State (`useState`)**: Understanding state initialization, updates, and triggering UI re-renders.
2. **Vite Development & HMR**: Leveraging Hot Module Replacement for instant updates during development.
3. **Modern CSS & Assets in React**: Integrating icons, SVGs, and responsive styles cleanly into React components.

---

## ⚡ Quick Start

```bash
# Navigate to the React Practice folder
cd "React Practice"

# Install project dependencies
npm install

# Start the Vite development server
npm run dev
```

*Open your browser and visit `http://localhost:5173` to explore the interactive playground.*

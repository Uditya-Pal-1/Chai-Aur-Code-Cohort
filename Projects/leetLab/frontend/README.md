# ⚡ LeetLab - Frontend

This is the frontend client for **LeetLab**, built with React 19, Vite, Tailwind CSS v4, and DaisyUI.

> For full project documentation, architecture, and setup guide, please refer to the main [LeetLab Readme](../Readme.md).

## 🚀 Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + DaisyUI v5
- **Routing**: React Router v7
- **Forms & Validation**: React Hook Form + Zod
- **Icons**: Lucide React

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the root of the `frontend` directory:
```env
VITE_API_BASE_URL="http://localhost:8080/api/v1"
```

### 3. Run Development Server
```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### 4. Production Build
```bash
npm run build
```

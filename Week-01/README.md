## The story of this week

Every web page starts as an idea: perhaps a heading, a short introduction, or a tiny profile. In Week 01, that idea becomes a real document. HTML gives the content a meaningful structure; Markdown helps explain the work; CSS brings the page to life with spacing, sizing, color, and positioning. Along the way, Git practice introduces the habits that help a developer experiment, track progress, and build with others.

This is the foundation layer: small examples, clear concepts, and plenty of room to try things, break them, and understand why they work.

## What you'll practice

- Build and inspect basic HTML documents.
- Use headings, paragraphs, metadata, and other document structure.
- Write and read Markdown for project notes and documentation.
- Explore CSS fundamentals, including the box model, units, sizing, and positioning.
- Get familiar with collaborative project files and version-control practice.

## Open the exercises

These are plain HTML files, so no package installation or build step is required:

1. Open this repository in VS Code.
2. Choose an `.html` file from `HTML/` or `css-basics/`.
3. Open it in a browser, or use the Live Server extension if it is installed.
4. Edit the markup or styles, refresh the page, and compare the result.

## A good way to learn

Keep each experiment small. Before changing a CSS value, guess what it will do. Make the change, check the browser, and write down what surprised you. Then revisit the example later and see whether you can explain it without looking at the code.

By the end of this week, a blank page should feel less blank: you can give it structure, make it your own, and understand the first steps toward working on a project with other developers.

## 📖 Overview

Welcome to **Week 12** of the **Chai Aur Code Cohort**! This repository serves as a showcase of 13 machine coding challenges and interactive JavaScript projects. Each project addresses a core frontend engineering challenge—from real-time input analysis and asynchronous timers to bitwise color computations and interactive drag-and-drop state management.

---

## 🎯 Key Learning Objectives

- **DOM Selection & Mutation**: Navigating the Document Object Model, manipulating node attributes, classes, and inner content dynamically.
- **Event-Driven Architecture**: Harnessing `click`, `input`, `keyup`, `change`, `dragstart`, `drop`, and form submit events.
- **Timing & Asynchronous APIs**: Managing execution loops and temporal updates using `setInterval`, `clearInterval`, and `setTimeout`.
- **Mathematical Logic & Bitwise Operations**: Implementing custom calculations (e.g., bitwise XOR complementary hex matching, tip splitting algorithms, regex string matching).
- **Clipboard & Web APIs**: Integrating `navigator.clipboard` for seamless user feedback and copy workflows.
- **Modular Component Design**: Architecting structured HTML, clean custom CSS UI layouts, and decoupled JavaScript source code.

## 🚀 Getting Started

To explore and run any of the projects locally on your computer:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Uditya-Pal-1/Chai-Aur-Code-Cohort.git
   ```

2. **Navigate to Week-12:**
   ```bash
   cd Chai-Aur-Code-Cohort/Week-12
   ```

3. **Run a Project:**
   - Open `index.html` in your web browser.
   - Alternatively, open any project folder under `Projects/` (e.g., `Projects/KanBanBoard/index.html`) directly in your browser or launch it using **VS Code Live Server**.
